# ✍️ AIライティングツール（個人用）

Python + Streamlit + Gemini API で動く、文章作成ツールをひとつにまとめたアプリです。
データベースやログインはなく、自分のPCで起動して使います。

## できること

| ツール | 内容 |
| --- | --- |
| 📰 ブログ執筆 | テーマ・キーワード・読者・文字数から、見出し構成つきの記事を作成（タイトル案・メタディスクリプション付き） |
| ✉️ メール作成・返信 | 受信メールへの返信や新規メールを、相手との関係とトーンに合わせて複数案作成 |
| 📋 要約 | 貼り付けた文章や PDF / テキストファイルを、箇条書き・3行・レポート形式などで要約 |
| 🖊️ 校正・リライト | 誤字脱字チェック、読みやすく書き直し、敬語化、短縮・加筆（変更点の一覧付き） |
| 🌐 翻訳 | 自然な訳文と、ニュアンスの解説 |
| 📱 SNS投稿 | X・Instagram・Threads などの媒体に合わせた投稿文 |
| 💡 タイトル・キャッチコピー | 記事タイトル・コピー・メール件名・ネーミングの案を表で一覧化、おすすめTOP3付き |
| 🧠 アイデア出し・構成案 | ネタ出し、記事のアウトライン、企画案などのブレスト |
| 🗂️ メモ整形・議事録 | 走り書きや文字起こしを、議事録・ToDo・報告書・日報に整形 |
| 💬 自由チャット | フォームにない相談を会話形式で |
| 📜 履歴 | このセッションで生成した結果を一覧・まとめてダウンロード |

各ツール共通で、

- 結果はリアルタイムに表示される（ストリーミング）
- **🔁 修正指示**で「もっと短く」「結論を先に」などと続けて直せる（前の結果と会話を踏まえて書き直す）
- Markdown / テキストでダウンロードでき、コピー用の欄もある
- サイドバーでモデルと創造性（temperature）を切り替えられる
- 別のツールに切り替えても入力内容は残る

## セットアップ（Windows / PowerShell）

```powershell
# 1. 仮想環境を作って有効化
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 2. ライブラリをインストール
pip install -r requirements.txt

# 3. APIキーを設定（.env.example をコピーして編集）
Copy-Item .env.example .env
notepad .env
```

APIキーは [Google AI Studio](https://aistudio.google.com/apikey) で取得できます。
`.env` を作らずに、起動後のサイドバー「⚙️ 設定」から入力することもできます（その場合はブラウザを再読み込みするたびに入力が必要です）。

## 起動

```powershell
.\.venv\Scripts\Activate.ps1
streamlit run app.py
```

ブラウザで http://localhost:8501 が開きます。

## ファイル構成

```
app.py        画面（サイドバー、ツールページ、チャット、履歴）
tools.py      各ツールの入力項目とプロンプトの定義
gemini.py     Gemini API の呼び出し（ストリーミング、モデル一覧の取得）
.env          APIキー（自分で作成。Git には含めない）
```

## ツールの追加方法

`tools.py` に `build_xxx(v)` 関数（入力値からプロンプトを作る）と `Tool(...)` の定義を書き、
末尾の `TOOLS` リストに加えるだけです。入力フォームは `fields` の定義から自動で作られます。

使える入力タイプ: `text` / `textarea` / `select` / `multiselect` / `slider` / `checkbox` / `file`

## 注意

- 履歴はブラウザを再読み込みすると消えます。残したい結果はダウンロードしてください。
- 入力した文章は Gemini API（Google）に送信されます。無料枠では入力内容がサービス改善に使われる場合があるので、機密情報の扱いには気をつけてください。
